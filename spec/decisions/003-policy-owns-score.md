# ADR-003：策略引擎拥有最终风险分数

- 状态：Accepted
- 日期：2026-08-14
- 范围：AI 与业务边界

## 背景

模型擅长总结和语义解释，但输出可能不稳定、缺少证据或受 Prompt 注入影响。若直接把模型返回的分数或严重级别作为门禁，系统会难以复现，也容易误报。

## 决策

- 确定性分析器负责事实和基础信号。
- 模型只返回候选 finding、证据、影响和建议。
- Go 端验证路径、行号、数量、严重程度和证据完整性。
- `policy` 根据稳定规则计算最终分数和风险级别。
- 默认不阻塞合并；门禁必须由显式配置开启并通过评测门槛。

## 结果

同一规则版本、输入和策略可以复现确定性评分。模型更换不会直接改变权限、门禁或评论发布边界。
